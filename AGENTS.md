# MATLAB Development Instructions

- This project uses MATLAB R2021b on Windows.
- Generate only MATLAB R2021b-compatible code.
- MATLAB executable: `C:\Program Files\MATLAB\R2021b\bin\matlab.exe`
- Use the installed MATLAB executable to run and test scripts.
- Use PowerShell syntax for terminal commands.
- Inspect MATLAB errors and fix them when possible.
- Do not assume newer MATLAB functions or toolboxes are available.
- Preserve compatibility with the existing MATLAB installation.
- Ask before modifying or deleting important project files.
